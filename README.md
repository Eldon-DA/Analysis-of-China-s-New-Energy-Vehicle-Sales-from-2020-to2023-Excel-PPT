# 2020-2023年中国新能源汽车销量分析
## 一、项目背景
2020-2023 年是中国新能源汽车行业从政策驱动转向市场驱动的关键爆发期，行业整体销量实现跨越式增长，市场格局、品牌竞争态势均发生深刻变化。本项目基于全量月度销量数据，开展多维度、全周期的数据分析，挖掘行业发展规律、市场竞争格局与用户需求特征，为行业研究、企业决策提供数据支撑与分析参考。
## 二、项目简介
本项目针对2020年1月-2023年12月中国新能源汽车全量销量数据开展完整的数据分析全流程工作，覆盖数据清洗与标准化、多维度透视分析、趋势分析、竞争格局分析、行业集中度分析，最终输出结构化的数据分析Excel文件与完整的可视化分析报告PPT，展示2020-2023年中国新能源汽车市场的发展全貌。
## 三、数据说明
1. 原始数据下载自和鲸社区公开数据集《2020-2023年电动车销量》，数据由平台用户整合行业公开销量信息整理而成，仅用于学习与行业分析用途。未经授权，不得用于商业盈利用途。
2. 基础信息
   统计周期：2020年1月-2023年12月，共48个月的月度连续数据。
   数据覆盖：106家新能源汽车厂商、323款在售车型。
   数据规模：原始数据共8106条，清洗后有效分析数据7245条。
3. 字段说明
   年份：数据统计年份
   月份：数据统计月份
   厂商：新能源汽车品牌厂商名称
   车型：对应厂商的具体车型名称
   售价（万元）：车型官方指导价区间
   起售价（万元）：车型入门版本官方指导价
   顶配价（万元）：车型顶配版本官方指导价
   平均客单价（万元）：车型指导价区间平均值，用于销售额测算
   价格区间：车型所属价格分段（10万以下/10-20万/20-30万/30-40万/40-50万/50万及以上）
   销量：对应车型当月销量数据
   销售额（万元）：对应车型当月测算销售额（平均客单价*当月销量）
## 四、分析框架
本项目围绕新能源汽车市场核心分析维度，搭建完整的分析体系，具体如下：
1. 市场整体规模与增长趋势分析：年度累计销量增长测算、月度销量季节性规律分析、行业整体增长率分析
2. 厂商竞争格局分析：全周期厂商销量排名、市场份额占比拆解、品牌表现对比
3. 车型销量表现分析：全周期热销车型TOP榜、厂商核心车型竞争力分析
4. 价格区间分布分析：不同价格段的累计销量占比、用户消费主流分析
5. 行业集中度分析：2020-2023年CR3/CR5/CR10指标变化趋势、市场竞争格局演变规律
